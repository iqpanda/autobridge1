# AutoBridge
Fabric client mod for 26.2: automatic speed bridging with any block. Toggle with R.

GitHub build:
1. Upload everything in this folder to a new GitHub repo (github-workflow.yml is a normal file, fine to upload).
2. On the repo: Actions tab -> "set up a workflow yourself" -> paste the contents of github-workflow.yml -> Commit.
3. Actions tab -> wait for the build -> download autobridge-jar from Artifacts.

Or build locally with build.bat / build.sh (needs JDK 25).
